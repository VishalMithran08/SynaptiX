# Installable requirements for running run.py and reproducing training.
#
# These are deliberately minimum-version specifiers rather than a literal
# `pip freeze`. The training environment used a PyTorch NIGHTLY build
# (torch==2.12.0.dev20260408+cu128) because the GPU used for development is an
# RTX 5060 (compute capability 12.0), which stable wheels of the time did not
# yet support. Pinning that nightly exactly would make this file
# uninstallable on any other machine -- nightly wheels are removed from the
# index and require a custom --index-url.
#
# The exact environment is recorded verbatim in requirements-frozen.txt for
# reproducibility. This file is what you should install to RUN the model.
#
#   pip install -r requirements.txt
#
# GPU SUPPORT DIFFERS BY PLATFORM -- this matters.
#
#   Linux x86_64:  nothing extra. PyPI's torch wheel declares the CUDA
#                  runtime, cuDNN, cuBLAS and NCCL as dependencies gated to
#                  platform_system == "Linux", so `pip install -r
#                  requirements.txt` already gives a CUDA-capable build.
#
#   Windows:       the default PyPI wheel is CPU-ONLY (241 MB, versus 888 MB
#                  for the Linux CUDA wheel). To use an NVIDIA GPU, install
#                  the CUDA build BEFORE this file:
#
#                    pip install torch torchvision #                        --index-url https://download.pytorch.org/whl/cu128
#
#                  cu128 covers compute capability 7.0-12.0: V100, A100,
#                  H100, and RTX 20/30/40/50-series.
#
# Either way the model produces identical results -- run.py falls back to CPU
# automatically and prints which device it chose. Only speed differs.

torch>=2.1
torchvision>=0.16
numpy>=1.24
Pillow>=9.5
tqdm>=4.65

# Training only (not needed for inference):
scipy>=1.10

# Optional. Enables the LPIPS metric in tools/eval_report.py --lpips.
# Inference and training both work without it.
lpips==0.1.4

# Optional. Supplies the bundled photographs used by
# tools/content_shift.py --builtin (the content-shift generalisation test).
